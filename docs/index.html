O PROJETO

Teoria e código no mesmo ambiente.

As aulas foram desenvolvidas em Markdown e convertidas em apresentações Reveal.js. Os laboratórios interativos são componentes JavaScript independentes: podem ser reutilizados em diferentes aulas sem duplicar código.

Material didático inicial, destinado a demonstrações acadêmicas. Dados e modelos simplificados nos laboratórios não substituem simuladores de fluxo de potência ou estimadores de produção.

GUIA RÁPIDO

Como navegar nas apresentações

Use as setas para avançar e retroceder. Pressione Esc para visualizar a estrutura geral e S para abrir as notas do apresentador. Os laboratórios permitem alterar parâmetros enquanto os resultados são calculados no navegador.
